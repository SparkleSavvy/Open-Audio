OPEN AUDIO

Minimalist music streaming you host yourself. Like SoundCloud, but without the limits — free uploads, free downloads, and moderation run by your own community.

Get started Read the docs

OPUS · FLAC · WAV · ALAC — served byte-for-byte, no transcoding

No transcoding

Files stream exactly as uploaded. What an artist renders is what a listener gets.

Hi-Res ready

Lossless audio up to 192 kHz / 24-bit, tagged automatically from the file itself.

Zero external DB

SQLite through built-in node:sqlite — one process, one port, no services to babysit.

Everything a listening community needs.

Eight primitives that cover the whole loop — upload, review, listen, download — with nothing you have to switch off.

Animated player

Queue, seek, volume and smooth track transitions in a strict monochrome UI.

Free downloads

Opus tracks for everyone; lossless FLAC/WAV/ALAC reserved for Supporters.

Auto-metadata

Title, artist, cover, bitrate and sample rate parsed from tags on upload.

Community moderation

Every upload passes human review — verify, reject or suspend — before the feed.

Notification center

Status changes land in the bell with a reason attached. Nobody guesses.

Roles & Supporter

Owner, admin and user roles, plus a Supporter badge that unlocks lossless.

Admin CLI

Backups, role changes, secret rotation, orphan cleanup — all scriptable.

Hardened by default

Magic-byte validation, rate limits, brute-force locks, httpOnly JWT cookies.

Uploads meet human review.

Nothing auto-publishes. A track becomes public only after a moderator looks at it — and every decision comes with a notification.

01

Upload

A user drops an Opus or lossless file. Metadata and cover fill themselves in.

02

Pending

The track enters the queue, visible to its author under My uploads.

03

Review

Moderators verify, reject with a written reason, or suspend temporarily.

04

Live

Verified tracks hit the feed and search; the uploader is notified instantly.

Owners confirm deletions requested by moderators — nothing disappears silently.

Quality you can read at a glance.

Every card shows its exact technical profile — sample rate, bit depth, bitrate — sorted into three honest categories.

  • Hi-Res — lossless, 24-bit, 44.1–192 kHz
  • Hi-Fi / CD quality — lossless, 16-bit, 44.1 kHz+
  • Standard / HQ — everything else, still served untouched

Own your stack in three commands.

No Postgres to migrate to, no Redis to babysit. State is one SQLite file and one uploads folder — copy them and you are backed up.

  • Node.js 22.5+ (Node 24 recommended)
  • Docker Compose and Kubernetes manifests included
  • systemd service via ./open-audio install --service
