FAQ & troubleshooting

Short answers to the questions that come up on day one.

Why is the feed empty after install?

By design. Tracks appear only through the pipeline: someone uploads, a moderator verifies. Upload something and approve it in /admin to see the loop work.

Which format should I upload?

Whatever you master in. Opus for everyday releases (small, streams everywhere); FLAC/WAV when fidelity matters — listeners with the Supporter badge will get the lossless file, others still stream and download Opus freely.

Why can't I download a FLAC track?

Lossless downloads are reserved for Supporters and the owner. Opus downloads stay free for everyone; ask your instance owner about the badge — see Supporter.

Can I make the server transcode to MP3?

No. Serving byte-for-byte is a core principle — no transcoding layer exists to turn off.

Can I run multiple replicas behind a load balancer?

Not yet: SQLite takes one writer, uploads live on local disk, and the rate limiter is in-memory. Run one replica on a bigger node; the migration path is described in Deployment.

I lost the owner password.

npm run admin account owner resets it. Any admin can do the same for moderator accounts.

How do I rotate secrets?

npm run admin secret rotates JWT_SECRET — all sessions die and TOTP enrollments reset. npm run admin removal-key rotates the removal key. Both land in .env and take effect on restart.

Where does my data live, and how do I back it up?

Two paths from .env: DATABASE_PATH (SQLite, WAL) and UPLOAD_DIR. npm run admin backup [dir] snapshots both consistently.

Something suspicious was uploaded.

Suspend it from /admin — playback stops instantly while the case is checked. File-format tricks should already have been caught by magic-byte validation.

What license applies?

MIT. Self-host it, fork it, ship it.
