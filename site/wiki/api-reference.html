HTTP API reference

Every endpoint under /api, grouped by router. Cookie-authenticated JSON, no API keys.

Conventions. All routes are prefixed with /api. Authentication rides in an httpOnly JWT cookie — send credentials: include. Errors are JSON { "error": "..." }. Rate limits: 300 req / 15 min per IP globally, 20 req / 15 min for auth routes.
