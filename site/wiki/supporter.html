Supporter badge & lossless access

One badge, one privilege: downloading lossless audio.

The Supporter badge marks people who back the project. In the UI it appears as a small heart pill next to the username, and it carries exactly one superpower: downloading lossless tracks (FLAC/WAV/ALAC). Everyone else keeps free Opus downloads — the badge gates fidelity, not participation.

Granting

Only the owner can grant or revoke the badge:

  • Admin panel — Users tab, toggle on the user row.
  • CLI — npm run admin user <id> supporter on|off
grant supporter 
$ npm run admin user 42 supporter on   # grant
$ npm run admin user 42 supporter off  # revoke

How enforcement works

The download endpoint re-checks the badge live on every request — revoking it takes effect immediately, no cached URLs survive. Playback is never restricted: supporters get files, everyone gets music.
