Feature reference

Everything the box ships with, grouped by what it does for whom.

Listening

  • Animated player — persistent bar with queue, seek, volume and smooth animated transitions between tracks.
  • Waveform seekbar — every track renders a real waveform you can scrub.
  • Feed — latest and popular sorts, cover-first grid.
  • Search — across track titles and artists.
  • Likes & counters — likes and play counts on every track.
  • Library & social graph — reposts, follows, personal library.

Uploading

  • Strict format policy — Opus (Ogg/WebM/Matroska) and lossless FLAC/WAV/ALAC only; see Uploads & formats.
  • Auto-metadata — title, artist, duration, cover and technical parameters parsed from file tags on upload.
  • Quality badges — Hi-Res, Hi-Fi/CD and Standard/HQ derived from real bit depth and sample rate.
  • Resubmission — a rejected track can be edited and sent back to review.

Downloads

  • Free Opus downloads — every verified Opus track downloads freely, no payment and no tier.
  • Lossless for Supporters — FLAC/WAV/ALAC downloads unlock for Supporter-badge holders and the owner; see Supporter.

Moderation

  • Status pipeline — pending, verified, rejected, suspended; deleted tracks leave the database entirely.
  • Reasoned rejections — the author sees the reason and can resubmit.
  • Suspension — temporarily kills playback and downloads while keeping the card visible.
  • Delete requests — moderators propose deletions; only the owner confirms them.
  • Notifications — every status change notifies the uploader; details in Moderation & roles.

Accounts & roles

  • Roles — owner, admin (moderator) and user with an explicit capability matrix.
  • Two-factor login — optional TOTP second factor.
  • Supporter badge — granted by the owner, unlocks lossless downloads.
  • Bans — banned sessions are force-cleared on their next request.
  • Inactivity purge — CLI-driven cleanup of dormant accounts with protected classes.

Administration

  • Admin panel — Moderation, Users, Delete requests and platform statistics tabs.
  • Audit log — every admin action from API and CLI lands in admin_log.
  • Admin CLI — the full management surface; see the CLI reference.
  • Backups — snapshot DB via VACUUM INTO plus a copy of uploads in one command.
