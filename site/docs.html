What is Open Audio?

A minimalist, self-hosted music service with a dark monochrome look. Like SoundCloud, but without the limits.

Open Audio is a single Node.js process that hosts your music community end to end: users upload Opus or lossless tracks, moderators review them, and everyone streams or downloads straight from your own server. There is no transcoding layer, no recommendation engine, and no external database — the whole state of the world is one SQLite file and one folder of uploaded media.

Design principles

  • Files are sacred. Audio is served byte-for-byte as uploaded. No transcoding, ever — an artist's master is what listeners get.
  • Downloads are free by default. Opus tracks download freely; lossless (FLAC/WAV/ALAC) is reserved for Supporters and the owner.
  • Humans curate. Nothing auto-publishes. A moderator verifies, rejects with a reason, or suspends — and the uploader is notified either way.
  • One process, zero services. SQLite through built-in node:sqlite, JWT in an httpOnly cookie, static file serving. Copy two paths and you have a backup.

How it fits together

Browser      React 19 SPA (Vite, Tailwind 4)
   │            fetch(..., credentials: include)
   ▼
/api         Express routers: auth · tracks · upload
   │          admin · notifications · users · studio
   │
   ├────────────────► node:sqlite   users, tracks,
   │                  (WAL mode)    likes, comments…
   ▼
/uploads     audio + covers on disk, streamed
              as-is, path-traversal guarded

The browser client talks only to /api; authentication rides in an httpOnly JWT cookie, so there are no tokens in localStorage. Uploaded media lives outside the database and is streamed by the same Express process under /uploads.
