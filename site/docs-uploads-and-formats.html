Formats, validation & metadata

What you can upload, how the server checks it, and what gets extracted along the way.

Accepted formats

FormatContainerClass
OpusOgg / WebM / MatroskaStreaming codec — free downloads
FLAC.flacLossless — Supporter downloads
WAVPCMLossless — Supporter downloads
ALACM4A / MP4Lossless — Supporter downloads

Cover art may be JPEG, PNG, WebP or GIF. Files are served exactly as uploaded — the platform never transcodes. Maximum upload size is 60 MB; put a reverse proxy in front, raise its body limit to 64 MB.

Content validation

Both the declared mimetype and the actual bytes are checked. The server reads magic numbers (OPUS/OGG/WebM/FLAC/WAV/M4A signatures for audio, image signatures for covers) and rejects anything that does not match the policy — an HTML or script payload renamed to .opus never reaches disk.

Automatic metadata

Parsed with music-metadata at upload time:

  • Title, artist, duration
  • Embedded cover art
  • Bitrate, sample rate, bit depth
  • Codec, container, lossless flag

Cover, artist and title are required — taken from the form or falling back to the file tags, whichever you fill.
